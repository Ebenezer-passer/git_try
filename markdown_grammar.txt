A、标题
1、使用====和----标记一级和二级标题
eg.
一级标题
========
二级标题
-------

2、使用#标记，一个#对应一级标题，两个#对应二级标题，类推至六级
eg.
# 一级标题
## 二级标题
###### 六级标题
注意：#和标题之间应有一个空格

B、文本
1、采用空行来分隔段落
eg.
段落1

段落2

段落基本规则：
段落由一个或多个连续的文本行组成
段落之间由一个或多个空行分隔
普通段落不应该用空格或制表符缩进

最佳实践建议：
在标题和内容之间留空行
在列表前后留空行
在代码块前后留空行
保持一致的空行使用习惯

不创建新段落强制换行：在行尾添加两个或更多空格，然后回车
<br>:HTML格式的强制换行

2、字体，**粗体**或__粗体__;*斜体*或_斜体_;***粗斜体***或___粗斜体___
注意下划线的数目依次为2/1/3

3、分隔线，在一行中采用三个以上的* - _来建立一个分隔线
但常用的是------------

4、删除线，在文字的两端加上两个~，如~~baidu~~

5、下划线，md格式无法直接设置，可通过HTML的<u>标签实现
eg.<u>underline<u>

6、脚注，使用[^要注明的文本]
eg.创建脚注格式类似这样 [^gold]。

[^gold]: 作脚注说明

7、行内代码标记，使用一个`包围代码（反引号）
eg.使用`git commit`提交代码
注意：如果代码本身包括反引号，需要用两个反引号包围
eg.要显示反引号，使用 `` `code` `` 这样的格式

代码区块使用 4 个空格或者一个制表符（Tab 键）
eg.
正常文本段落

    这是缩进式代码块，前后需要空行分隔
    每行前面有四个空格
    保持代码的原始格式
    
继续正常文本

也可以用 ``` 包裹一段代码,在三反引号后添加语言标识符可以启用语法高亮功能
eg.
```
多行代码内容
可以包含空行
保持原有缩进
```

8、文本高亮，非md格式标准语法，用两个=包围
eg.这是==高亮文本==
eg.这是<mark>高亮文本</mark>  HTML替代方案

C、列表
1、无序列表，使用* + -作为列表标记，标记后面要添加一个空格
2、有序列表，使用数字加.，同样注意空格
3、任务列表
- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个未完成的任务

D、引用块
1、单级引用，在段落开头加上>，后面紧跟一个空格
eg. > 区块引用

> 这是引用的第一行。
> 这是引用的第二行。
> 
> 这是引用的第二段。

> 这是一个长引用，
包含多行内容，
只需要在第一行使用 > 符号。

2、多级嵌套引用，一个 > 符号是最外层，两个 > 符号是第一层嵌套，以此类推：
> 最外层
> > 第一层嵌套
> > > 第二层嵌套

| 场景 | 路径写法 | 示例说明 |
|------|----------|----------|
| 图片与 Markdown 文件同目录 | 直接写文件名 | `![Logo](logo.png)` |
| 图片在子目录 | `子目录名/文件名` | `![截图](images/screenshot.jpg)` |
| 图片在父目录 | `../文件名` | `![图标](../assets/icon.svg)` |
| 图片在更深层目录 | `../父目录/子目录/文件名` | `![图表](../docs/images/chart.png)` |

✅ 关键原则：
相对路径的起点 = Markdown 文件所在目录
../ 表示“上一级目录”，./ 表示“当前目录”（通常可省略）
推荐使用相对路径

G、表格
使用 | 来分隔不同的单元格，使用 - 来分隔表头和其他行
|  表头   | 表头  |
|  ----  | ----  |
| 单元格  | 单元格 |
| 单元格  | 单元格 |

可以设置表格的对齐方式：

---: 设置内容和标题栏居右对齐
:--- 设置内容和标题栏居左对齐
:---: 设置内容和标题栏居中对齐
